# VS Code Keybindings

This directory stores my exported VS Code keybindings in [`keybindings.json`](/Users/hi-matbub/.config/vscode/keybindings.json).

## Install

1. Open VS Code.
2. Open the Command Palette with `Cmd+Shift+P`.
3. Run `Preferences: Open Keyboard Shortcuts (JSON)`.
4. Copy the contents of [`keybindings.json`](/Users/hi-matbub/.config/vscode/keybindings.json) into your VS Code keybindings file.
5. Save the file.

## macOS keybindings file

VS Code usually stores user keybindings here:

```text
~/Library/Application Support/Code/User/keybindings.json
```

## Notes

- These bindings are written for macOS-style VS Code shortcuts.
- If you already have custom keybindings, merge carefully instead of overwriting the whole file.
