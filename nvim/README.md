# Neovim Configuration

## Harpoon Keybindings

| Key | Action |
|-----|--------|
| `<leader>ha` | Add file to harpoon |
| `<leader>hm` | Toggle harpoon menu |
| `<leader>hr` | Remove current file from harpoon |
| `<leader>hc` | Clear all harpoon marks |
| `<leader>h1` | Go to harpoon file 1 |
| `<leader>h2` | Go to harpoon file 2 |
| `<leader>h3` | Go to harpoon file 3 |
| `<leader>h4` | Go to harpoon file 4 |
| `<leader>hp` | Previous harpoon file |
| `<leader>hn` | Next harpoon file |

## Gitsigns Keybindings

### Navigation
| Key | Action |
|-----|--------|
| `]c` | Jump to next git change |
| `[c` | Jump to previous git change |

### Actions
| Key | Mode | Action |
|-----|------|--------|
| `<leader>hs` | Visual | Git stage hunk |
| `<leader>hr` | Visual | Git reset hunk |
| `<leader>gs` | Normal | Git stage hunk |
| `<leader>gr` | Normal | Git reset hunk |
| `<leader>gS` | Normal | Git stage buffer |
| `<leader>gu` | Normal | Git undo stage hunk |
| `<leader>gR` | Normal | Git reset buffer |
| `<leader>gp` | Normal | Git preview hunk |
| `<leader>gb` | Normal | Git blame line |
| `<leader>gd` | Normal | Git diff against index |
| `<leader>gD` | Normal | Git diff against last commit |

### Toggles
| Key | Action |
|-----|--------|
| `<leader>tb` | Toggle git show blame line |
| `<leader>tD` | Toggle git show deleted |
